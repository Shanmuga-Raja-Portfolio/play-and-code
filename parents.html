Play & Code — For Parents

Everything you need to know, in five minutes. 🌈

🎮 What this is

Play & Code is a collection of 9 free, completely offline games for kids. Your child plays a game first — then opens the in-game "Game Master Lab", a friendly control panel where they can change how the game actually works. Slide gravity down and watch the jumps float. Bump the speed up and try to keep up. That's the idea: play first, then peek under the hood and learn real coding ideas by doing.

🖱️ How to run

Double-click any game's index.html — it opens in any modern web browser (Chrome, Edge, Firefox, Safari). There is no install, no account, and no internet needed. Everything each game needs (including its Vue and Tailwind libraries) is bundled inside that game's lib/ folder.

Moving to another computer? Copy the whole game folder — including its lib/ folder — and it will keep working. Keep the root index.html next to the game folders and you get the pretty game-picker dashboard too.

🛡️ Kid-safe by design

  • No ads — there is no advertising code anywhere in the collection.
  • No external links — the games contain zero web addresses. You can verify this yourself: open any game's index.html in a text editor and search for "http"; the only match is a harmless technical string inside the emoji icon.
  • No accounts, no sign-ups, no email addresses.
  • No data collection — nothing is ever sent anywhere.
  • No purchases, no in-app stores, no loot boxes, no gambling-style randomness.
  • No energy meters, no wait timers, no daily streaks — nothing punishes a child for putting the game down.
  • Gentle fail states only: a bounce, a poof, a "Good try!" — never punishment language or scary imagery.
  • Progress is stored only in the browser's local storage on that computer. To wipe it, use the game's Settings → "Reset everything" button (it asks twice before wiping).

🧠 What kids learn — the Game Master Lab

Every game has a chunky "🛠️ Game Master" button on its menu screen. Inside the Lab:

  • Real controls, real variables. Sliders, toggles, and color/emoji pickers are wired to the actual constants in the game's code — gravity, speed, spawn rates, colors. Every change applies live, so the game visibly changes the instant a slider moves.
  • Short lesson cards. Friendly one-screen cards introduce coding ideas — variables, numbers, conditions ("if"), loops, and functions — each tied to the exact control your child is touching.
  • A mini code box. Kids can type simple assignments like gravity = 0.4 and see them take effect. This is handled by a small, safe parser: it only understands the game's known variable names and basic arithmetic, and results are clamped to safe ranges. It never runs arbitrary code — mistyped input just gets a friendly "Oops —" explanation.

Each game's README.md lists its lesson cards and the exact constants it exposes, so you know precisely what to explore together.

🤝 Helping your child

  • Suggested age: roughly 6–11. Younger kids will enjoy the play; older kids will dig deeper into the Lab.
  • Sit together for the first visit to a Game Master Lab — move one slider, play, move it again. The instant feedback is the whole lesson.
  • Ask "what happens if…?" and let them predict before they try. Wrong guesses are the best teachers, and "Reset to normal" is always one click away.
  • Ready for more? Each game's README.md has a "tweaking the game" section showing where those constants live in the real source code.
